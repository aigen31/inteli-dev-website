# Деплой сайта на прод

Прод: `root@152.228.118.128`, `/www/wwwroot/inteli-dev.ru`, ветка `production`.
aaPanel проксирует `inteli-dev.ru` на `127.0.0.1:18002` (nginx-контейнер),
поэтому compose запускается двумя файлами:

```bash
docker compose -f compose.yaml -f compose.aapanel.yml ...
```

## Деплой

```bash
DEPLOY_SSH_PASSWORD='...' scripts/deploy-prod.sh
```

Скрипт:

1. проверяет ветку `production` и чистое дерево;
2. пушит ветку в bare-репозиторий `/root/git/inteli-dev-site.git`;
3. перекрывает только файлы, которые ведёт репозиторий (список `FILES`):
   Rust-исходники виджета, стили и compose. Локальные правки aaPanel,
   `.env.prod`, `config/` и старые WIP-файлы не трогаются;
4. собирает образ `web` на сервере и перезапускает контейнер;
5. ждёт `http://127.0.0.1:18002/api/health` = 200.

## Источник занятости

Виджет «Приём заявок» читает CRM:

- `CRM_PUBLIC_URL` (по умолчанию `https://crm.inteli-dev.ru`);
- CRM endpoint `GET /api/public/availability` — агрегаты без названий задач;
- день занят, если назначено больше 4 задач;
- при недоступности CRM показывается последний снимок, до первого — значения
  из настроек сайта.

Админ-раздел «Приём заявок» удалён: контент виджета больше не редактируется
на сайте.
