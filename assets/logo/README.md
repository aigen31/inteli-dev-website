# Логотип: шляпа Кики

Знак — шляпа из той же one-line серии, что и hero-иллюстрация
(`assets/hero/hero-kiki-oneline-16x9.webp`). Генерация в ComfyUI дала форму,
форма переведена в вектор трассировкой контура. Вектор — источник правды, PNG
пересобираются из него.

## Правило размеров

- **До 48 px — белая заливка.** Тонкий контур в миниатюре исчезает: линия
  тоньше пикселя и hat превращается в грязь. Заливка держит силуэт.
- **От 180 px — тонкий контур.** На больших размерах видно линию, и она честнее
  показывает связь с иллюстрацией.

Поэтому в наборе два разных знака, а не один масштабированный.

## Вектор

| Файл | Что это |
|---|---|
| `hat-fill.svg` | заливка, `currentColor` |
| `hat-fill-light.svg` / `hat-fill-ink.svg` | заливка фиксированного цвета |
| `hat-line-thin.svg` | тонкий контур, `currentColor` |
| `hat-line-thin-light.svg` / `-ink.svg` | тонкий контур фиксированного цвета |
| `hat-line.svg` | толстая линия (первая итерация, запасной вариант) |
| `assets/favicon.svg` | тайл 64×64 с заливкой — favicon |
| `hat-tile-line.svg` | тайл с тонким контуром — большие иконки |

Внутри — один path с `fill-rule="evenodd"`: контур толстой линии трассирован
как замкнутая форма, поэтому SVG не зависит от шрифтов и толщин обводки.

## Растр (пересобирается из вектора)

| Файл | Размер |
|---|---|
| `hat-icon-fill-16/32/48.png` | favicon и мелкие иконки, заливка |
| `hat-icon-line-180/192/512/1024.png` | apple-touch, PWA, соцсети, контур |
| `hat-fill-64.png` | запасной PNG знака |
| `hat-line-512.png` | контур 512 без тайла |

## Стили-итерации

`variants/` — запись поиска: `hat-thin-line`, `hat-bold-line`, `hat-band`
(с фиолетовой лентой), `hat-solid`, `hat-badge` (в кольце), `hat-engraved`.
В продакшене используется `hat-bold-line` (контур) и `hat-solid` (заливка).

## Где стоит

- Шапка сайта: `/assets/logo/hat-fill.svg`, 26 px (на телефоне 24, текст прячется).
- Favicon: `/favicon.svg`; PNG-фолбэк 32 px — заливка.
- Apple-touch: 180 px, тонкий контур в тайле.
- PWA: 192 и 512, тонкий контур.
- `manifest.json`: `theme_color` и `background_color` — `#08080d`.

## Правила

- Охранное поле — не меньше 0.2 высоты знака.
- Минимум: 16 px для тайла, 24 px для знака без подложки.
- Цвет: `#f4f2ef` на тёмном, `#0a0a11` на светлом, акцент `#8b7ff5` — только
  в варианте с лентой.
- Не наклонять, не обводить, не добавлять тени и градиенты.
