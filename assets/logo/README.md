# Логотип inteli.dev

Знак — редукция иллюстрации «Кики в полёте» (`assets/hero/hero-kiki-oneline-16x9.webp`).
В иллюстрации фигура нарисована одной линией; в 16 px линия исчезает, поэтому
для знака она переведена в сплошной силуэт: шляпа, платье, вытянутая рука,
ботинки. Фиолетовая точка на конце руки — тот же акцент, что и в макете
(`#8b7ff5`), и одновременно «огонёк», к которому она тянется.

## Форматы

| Файл | Что это | Где использовать |
|---|---|---|
| `logo-mark.svg` | знак, `currentColor` (точка — `--logo-accent`) | инлайн в интерфейсе, любой размер от 24 px |
| `logo-mark-light.svg` | знак с фиксированным светлым цветом | тёмный фон, `<img>`, презентации |
| `logo-mark-compact.svg` | тот же знак, кадрированный по шляпе и торсу | 16–24 px, аватарки, где важна масса, а не ноги |
| `logo-tile.svg` | знак в тёмном скруглённом тайле | иконка приложения, favicon |
| `logo-tile-16/32/48/64/128/180/192/512/1024.png` | тайл в растре | favicon, apple-touch, PWA, соцсети |
| `logo-lockup.svg` | знак + `inteli.dev`, светлый текст | тёмный фон, шапка сайта, обложки |
| `logo-lockup-dark.svg` | то же, тёмный текст | светлый фон, документы, счёт-фактуры |
| `brand-sheet.png` | сводный лист | показать заказчику, бренд-гайд |

## Правила

- **Охранное поле** — не меньше высоты шляпы (примерно 0.25 высоты знака) со всех сторон.
- **Минимальный размер** — 24 px для полного знака, 16 px для `compact` и тайла.
- **Цвет** — знак одноцветный, акцент только точка. На тёмном это `#f4f2ef` +
  `#8b7ff5`, на светлом `#0a0a11` + `#6f63e8`.
- **Нельзя** наклонять, обводить, менять пропорции, заливать градиентом или
  ставить знак на пёструю фотографию без подложки.

## Сборка

SVG — источник правды. Растр пересобирается одной командой:

```sh
for s in 16 32 48 64 128 180 192 512 1024; do
  rsvg-convert -w "$s" -h "$s" assets/logo/logo-tile.svg -o "assets/logo/logo-tile-$s.png"
done
cp assets/logo/logo-tile-180.png assets/logo/apple-touch-icon.png
cp assets/logo/logo-tile.svg assets/favicon.svg
```

В приложении иконки встроены в бинарник (`src/api/assets.rs`) и отдаются по
`/favicon.svg`, `/apple-touch-icon.png`, `/icon-192.png`, `/icon-512.png`.
