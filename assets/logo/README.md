# Логотип: шляпа Кики

Знак — шляпа из той же one-line серии, что и hero-иллюстрация
(`assets/hero/hero-kiki-oneline-16x9.webp`). Нарисован не вектором, а генерацией:
несколько итераций и стилей в ComfyUI, из них выбрана одна и доведена до
иконочного вида. Вектора здесь нет намеренно — знак живёт растром в фиксированных
размерах, от 16 до 1024 px.

## Основной знак

| Файл | Что это |
|---|---|
| `hat-mark-white.png` | белая шляпа на прозрачном, 1024 px |
| `hat-mark-ink.png` | тёмная шляпа на прозрачном, 1024 px (для светлого фона) |
| `hat-mark-16/32/48/64/128/180/192/256/512/1024.png` | размерный ряд белого знака |
| `hat-line-*` | тонкая линия (первая итерация) — для крупных поверхностей |
| `hat-tile-16/32/48/64/128/180/192/256/512/1024.png` | знак в тёмном скруглённом тайле: favicon, PWA, соцсети |

## Стили-итерации

Лежат в `variants/` как запись поиска, не для продакшена:

- `hat-thin-line.png` — тонкая линия, ближе всего к иллюстрации.
- `hat-bold-line.png` — та же линия, но толще: выбран как основа знака, потому
  что 16 px тонкую линию съедает.
- `hat-band.png` — линия с фиолетовой лентой на тулье.
- `hat-solid.png` — сплошной силуэт с лентой: максимальная читаемость в миниатюре.
- `hat-badge.png` — тонкое кольцо вокруг шляпы: вариант для аватара.
- `hat-engraved.png` — гравюра, только для крупного формата.

## Где используется

- Шапка сайта: `/assets/logo/hat-mark-64.png`, 26 px (на телефоне — 24 px, текст
  прячется).
- Favicon: `hat-tile-32.png`; apple-touch — `hat-tile-180.png`; PWA — 192 и 512.
- `manifest.json` ссылается на тайлы 192/512, `theme_color` — `#08080d`.

## Правила

- Охранное поле — не меньше высоты тульи (примерно 0.2 высоты знака).
- Минимум: 16 px для тайла, 24 px для знака без подложки.
- Цвет: белый `#f4f2ef` на тёмном, чернильный `#0a0a11` на светлом. Лента в
  сплошном варианте — `#8b7ff5`.
- Не наклонять, не обводить, не добавлять тени и градиенты.

## Пересборка

Знак режется из генерации по яркости, центрируется и раскладывается по размерам
скриптом (Pillow): маска → альфа → размерный ряд → тайл. Если меняется
генерация, меняется только исходник в `variants/`, размеры пересобираются.
